# N-Piano-player

A cool, usefull and styled interactive piano with song-auto-play included. Programed in HTML, JAVASCRIPT and CSS

## Features

*   **Sounds are generated mathematically:** Using browsers native `AudioContext` and Oscilators.
*   **Simple UI:** Styled with css
*   **Two types of input:** You can either use the mouse or the keyboard (a,s,d,f,g,h,w,e,t,y)
*   **Auto-play function:** Now it can only play (*Happy birthday*) but I'm going to add more songs in the future.
